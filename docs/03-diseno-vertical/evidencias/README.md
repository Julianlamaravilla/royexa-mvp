# Evidencias

Incluya evidencias pequeñas, legibles y reproducibles, por ejemplo:

- salida de ejecución de pruebas en texto;
- informe HTML o XML generado por el framework de pruebas;
- resultado de una medición asociada a `EV-XX`;
- solicitud y respuesta de ejemplo sin secretos.

No incluya:

- dependencias descargadas;
- binarios de compilación innecesarios;
- credenciales o archivos `.env` reales;
- capturas como única evidencia cuando existe una salida exportable;
- grandes volcados de consola sin explicación.
